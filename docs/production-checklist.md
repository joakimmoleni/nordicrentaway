# Innan den riktiga hemsidan byts

Visningsversionen är separat. Följande är inte automatiskt klart för att den går att öppna.

1. Johan bekräftar tjänsternas exakta omfattning, kontaktuppgifter, bildtexter och slutliga engelska texter. Bekräfta prioriterade språk. Priser och omdömen visas inte utan separat godkännande.
2. Kontrollera aktuell juridisk information och policytexter. Sajten lägger inte till spårning eller formulärleverantör. Formulär måste få en verklig mottagare och granskad hantering innan det aktiveras; skicka inga testmejl utan tillstånd.
3. Ordna Johans personliga projektåtkomst. Prova en verklig textändring, lyckad preview-deploy och avgränsad återställning från hans arbetsflöde.
4. Inventera befintlig hosting och gamla URL:er. Besluta separat om produktionsdomän och relevanta omdirigeringar. Ändra inte DNS eller Holidayfuture inom preview-uppdraget.
5. Kontrollera riktiga Safari/iPhone/iPad och dator med de slutliga bilderna, tangentbord, kontaktvägar och externa bokningslänkar. Lokala testresultat är inte uppmätta trafikvärden för Core Web Vitals.
6. Kontrollera att endast dist publiceras. Ingen privat kund-/gästdata, hemlighet eller forskningsdokumentation får ingå. Aktivera produktionsflaggar först efter motsvarande verkliga godkännande, inte för att tysta validering.

För nuvarande preview: Pages måste vara aktiverat med Source GitHub Actions. Noindex behålls. Fungerande länk verifieras separat från lyckat bygge.
